# Licencias

**Licencias** muestra la licencia de cada firewall, leída del propio firewall: **Activa**, **Por vencer** (termina en 30 días o menos), **Vencida**, **Prueba**, **Sin licencia** o **Desconocida**, con el número de serie y la fecha de vencimiento.

<Shots items={[{"name": "licences", "caption": "Estado de la licencia, serie y vencimiento de cada firewall."}]} />

Usa los contadores y el filtro para ver qué renovar primero. La sección **Planes** lista las licencias semestrales, una por firewall. Habla con tu representante de Nexwall para renovar o comprar licencias.
