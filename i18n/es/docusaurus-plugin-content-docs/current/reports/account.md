# Cuenta

Abre **Cuenta** en el menú del usuario para cambiar tu **contraseña**, elegir el **idioma** (inglés, portugués o español) y activar la **autenticación en dos pasos** con una aplicación de autenticación. Recomendamos el 2FA para todos los usuarios.
