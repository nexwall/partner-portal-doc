# Conta

Abra **Conta** no menu do usuário para alterar a sua **senha**, escolher o **idioma** (inglês, português ou espanhol) e ativar a **autenticação em dois fatores** com um aplicativo autenticador. Recomendamos o 2FA para todos os usuários.
