# Usuários

Abra **Usuários** para ver as pessoas da sua empresa e das empresas abaixo. Clique em **Criar usuário** para adicionar um: nome, e-mail, empresa e função.

<Shots items={[{"name": "users", "caption": "A lista de usuários."}]} />

O novo usuário recebe um **e-mail de boas-vindas** no idioma da empresa, com um link para definir a senha. Você pode editar um usuário, redefinir a senha, suspendê-lo ou excluí-lo. Os usuários só veem dados da própria empresa e das que estão abaixo.
