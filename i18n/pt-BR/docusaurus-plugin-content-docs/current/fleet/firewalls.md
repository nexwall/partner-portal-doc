# Firewalls

**Firewalls** lista todos os firewalls dos seus clientes, lidos do controlador de cada cliente. Filtre pelo status: **Online**, **Offline**, **Não registrado** ou **Atualização disponível**.

De cada firewall você vê o cliente, o status, a versão e há quanto tempo está online. Os contadores no topo somam os totais.

<Shots items={[{"name": "firewalls", "caption": "Todos os firewalls com status e versão."}]} />

Clique em **Abrir no controlador** para entrar direto no controlador desse cliente, sem digitar senha. Adicionar um firewall, atualizá-lo e abrir o terminal são tarefas do controlador; veja a documentação do Cloud Controller.

Se o controlador de um cliente não responde, os firewalls dele não são listados e um aviso informa isso.
