# Troubleshooting

**I did not receive the welcome e-mail.** Check the spam folder and that the e-mail address is correct; an administrator can resend it by resetting the password.

**A customer's firewalls are not listed.** The notice says the controller is not answering or is still being prepared. Wait a few minutes and use **Refresh**.

**Open in controller does not work.** Allow pop-ups for the portal. If it still fails, try again in a moment; the controller may be restarting.

**The report has no data.** Open the customer's controller, go to **Reports** and generate the firewall reports first.

**I cannot see a menu item.** Your role or your company may not have it (for example Brand needs rebranding enabled).

**I paid but the firewall is not Active.** The firewall learns about the new plan at its next check-in with the licence server; the portal asks it to check in right after the plan is applied. Wait a few minutes and use **Refresh**. The firewall must be online and registered. If it is still not Active after an hour, contact **Support** with the order number.

**Licence shows Active but Plan shows No plan.** The firewall is still using a licence it received earlier. It updates at its next check-in.

**I cannot buy a plan.** Only users who can manage firewalls buy. Customer users cannot, buying is off while you impersonate another user, and a plan smaller than the current one is refused. For a firewall managed by a distributor, ask the distributor to allow renewal by resellers.

Still stuck? Use **Support** in the menu to contact Nexwall.
