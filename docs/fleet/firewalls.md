# Firewalls

**Firewalls** lists every firewall of your customers, read from each customer's controller. Filter by status: **Online**, **Offline**, **Not registered** or **Update available**.

For each firewall you see its customer, status, version and how long it has been online. Counters at the top add up the totals.

<Shots items={[{"name": "firewalls", "caption": "All firewalls with status and version."}]} />

Click **Open in controller** to sign in directly to that customer's controller, without typing a password. Adding a firewall, updating it and opening its terminal are done in the controller; see the Cloud Controller documentation.

If a customer's controller is not answering, its firewalls are not listed and a notice says so.
