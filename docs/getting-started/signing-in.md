# Signing in and the dashboard

Open the portal and sign in with the account you received by e-mail (the welcome message has your user name and a link to set your password). The sign-in page may ask for a code if you enabled two-factor authentication.

<Shots items={[{"name": "login", "caption": "The portal sign-in page."}]} />

The **Dashboard** shows total firewalls (online, offline, not registered), active licences (expiring and expired), alerts by severity and the endpoints of your company. Items that need attention are highlighted; click one to go to its page.

The help button in the top bar opens the page of this guide that matches the screen you are on. Change the language and your password in [Account](../reports/account.md).
